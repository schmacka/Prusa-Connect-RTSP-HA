# Changelog

The changelog lives with the add-on, at
[`prusa_connect_rtsp/CHANGELOG.md`](prusa_connect_rtsp/CHANGELOG.md).

That is the file the Home Assistant Supervisor renders in the add-on's
"Changelog" tab, so it is the single source of truth. This file used to carry a
second, hand-maintained copy that drifted out of date (it stopped at 1.3.2 while
the add-on shipped 1.3.5); it is now a pointer so the two cannot diverge again.
